Sandbag Suite

P+ Mod

A Project+ mod intended to make practicing and training easier and quicker

↓ .rel (v0.2)

Features

  • Ledgedash training, with auto-ledge return
  • Input visualization
  • Savestate restoration
    • Hold D-Pad Left for 0.5 seconds to save
    • Press D-Pad Right to instantly restore

Getting started

  • Download the .rel file above
  • Open Project+ Dolphin
  • Click "Config" and go to "Wii"
  • Set a directory for "SD Sync Folder"
  • Click "Unpack SD Card Now"
  • Open that directory, then go to Project+/pf/plugins/
  • Put the .rel file you downloaded in here
  • Back in the Dolphin Config menu, click "Pack SD Card Now"
  • Launch P+ like normal. If you see an SS v# watermark, it worked!
  • Navigate to Training Mode and hit L + R + D-Pad Up to open the menu
  • To uninstall, just delete the .rel file from your SD Sync directory and re-pack it
