StreamFighter

desktop

Desktop scoreboard manager for tournament streams. Update player names, scores, characters, and casters — changes push to your OBS overlays in real time.

↓ Windows ↓ Linux Game Packs ↗

Features

  • Pull brackets and sets directly from start.gg — pick a set and it fills in players, round, and best-of
  • Player and caster presets so you never re-type your regulars
  • Character and costume portraits rendered right on the overlay
  • Customizable overlay colors, fonts, and layouts (dual sidebar, single sidebar, between-games scene)
  • Game pack system — drop in art for any game, not just Melee
  • Outputs to OBS three ways: browser-source overlays, per-field text files, and a JSON snapshot
  • Settings and presets persist between sessions

Getting started

  • Download and run StreamFighter for your platform above
  • In OBS, add a Browser source pointing at http://localhost:35920/game (and http://localhost:35920/between for the between-games scene)
  • Drop your character art into the games/<game>/characters/ folders (portraits + stock icons)
  • Paste your start.gg API token in Settings to enable bracket and set pulling
  • Edit players, scores, and casters in the app — everything updates the overlay automatically
